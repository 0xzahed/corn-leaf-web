# 🌽 Corn Leaf Disease Detection System

Deep Learning Based Corn Leaf Disease Classification Using InceptionV3 CNN Architecture

## Features

- Detect 5 types of corn leaf conditions
- Bilingual support (English & Bengali)
- Real-time disease detection
- Treatment recommendations

## Classes

- Common Rust (কমন রাস্ট)
- Corn Leaf Blight (কর্ন লিফ ব্লাইট)
- Gray Leaf Spot (গ্রে লিফ স্পট)
- Healthy (সুস্থ)
- Maize Chlorotic Mottle Virus (MCMV)
